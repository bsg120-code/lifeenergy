## 2. PoC 진단 페이지 UI 스펙 (Diagnostic Page Assets)

**목표:** 사용자가 스스로 리스크를 체감하고, 우리의 솔루션이 이를 해결할 수 있다는 '권위적 공포'와 '안도감'을 동시에 느끼게 한다.

### A. [리스크 체험 섹션] - Deep Red Focus
*   **핵심 컴포넌트:** `Failure Vector Card` (실패 벡터 카테고리)
*   **스펙:** 무작위로 화면에 팝업되며, **Deep Red 배경**을 가짐.
    *   **애니메이션:** `[Jitter & Impact]` – 팝업 시 강한 떨림(High Frequency Jitter)과 날카로운 충격음(Impact SFX)이 동반되어 공포감을 조성한다.
    *   **데이터:** 법규 위반, 시스템 과부하 등 구체적인 실패 벡터를 나열하여 기술적 권위를 확보.
*   **인터랙션:** 사용자가 해당 카드에 마우스를 올리면(`Hover`), 리스크 게이지가 임계치(Threshold)를 넘어 급락하는 애니메이션이 발생한다.

### B. [솔루션 제시 섹션] - Cyan Blue Focus
*   **핵심 컴포넌트:** `Control Flow Diagram` (통제 흐름 다이어그램)
*   **스펙:** 전반적으로 **Cyan Blue/Base Tone**을 사용하며, 깔끔하고 간결한 플로우 차트로 구성.
    *   **애니메이션:** 데이터가 '검증 엔진'을 통과하는 과정을 명확하게 애니메이션화한다. (데이터 $\to$ 검증 $\to$ 기록)
    *   **강조:** `Audit Log` 컴포넌트가 핵심이며, 불변성(Immutability)이 강조되도록 미세한 '체인 링크' 같은 시각적 효과를 추가한다.

## 3. 핵심 전환 시퀀스 스펙 (T+0:35 ~ T+0:42) - [THE CLEANSING]

**목표:** Deep Red의 혼란(Chaos)을 Cyan Blue의 질서(Order)로 바꾸는 '정보 필터링 및 클렌징' 효과를 극대화한다. 이 전환은 단순한 색상 변화가 아닌, **시스템적 상태 전환**을 의미해야 한다.

| 시간 구간 | 시각적 이벤트 | 애니메이션 스펙 (기술 지침) | 사운드/BGM 가이드 |
| :--- | :--- | :--- | :--- |
| **T+0:35 ~ T+0:37** | **[위기 고조의 정점]** Deep Red 오버레이가 최대로 치솟음. 리스크 그래프가 최대치에 도달하며 화면 전체가 노이즈로 뒤덮임. | 모든 시각 요소가 무작위적으로 깜빡이며, **Deep Red (`#9F222B`) 색상의 고주파 진동**이 배경을 지배함. (최대 혼란 상태) | BGM의 서브 베이스 럼블(Sub-Bass Rumble)이 최고조에 달하며, 사이렌 알람 사운드가 가장 크게 발생함. |
| **T+0:37 ~ T+0:40** | **[정보 필터링 개시]** 시스템이 강제적으로 '클렌징' 모드 진입을 선언함. (The Filter Activation) | 1. 화면 중앙에서 노란색(`Accent`)의 **'필터 그리드'**가 사선으로 빠르게 교차하며 전경을 가로지름. <br>2. 이 그리드를 통과하는 순간, Deep Red 요소들이 마치 데이터 손상처럼 `Glitch Effect`를 일으키며 사라짐. <br>**3. 배경 오버레이 색상이 급격히 Dark/Base Tone으로 전환되며 노이즈가 걷힘.** | **[CRITICAL SFX]** 모든 BGM이 일시적으로 '컷오프(Cut-off)'되고, 대신 기계적인 `WHIRRING` 사운드와 데이터 처리음 (`BEEP`, `CLICK`)만 강조됨. (기술적 정밀함 부각) |
| **T+0:40 ~ T+0:42** | **[통제력 확보]** 청명한 Cyan Blue의 '진실'이 드러남. (The Revelation) | 1. 필터 그리드가 완전히 사라지며, 화면 전체가 **Cyan Blue (`#00A8E0`) 톤**으로 재설정됨. <br>2. 기존의 혼란스러운 요소들은 간결하고 정돈된 플로우 차트(Control Flow Diagram)로 *재구성*되어 나타남. (모든 것이 질서 있게 배치되는 애니메이션). | BGM이 갑자기 **명료한 톤**으로 전환되며, 안도감과 자신감을 주는 청량한 화음(Major Chord)을 사용하여 임팩트를 극대화함. |
